# cpt-tracker: start.gg 中継（GAS）セットアップ

静的ページからstart.gg APIは直接呼べない（APIトークンが必須で、公開リポジトリに埋め込めない）ため、トークンを預かる小さな中継をGoogle Apps Scriptで立てる。所要10分。

## 1. start.ggのトークンを発行

1. start.ggにログイン → 右上のアイコン → **Developer Settings**（https://start.gg/admin/profile/developer）
2. **Create new token**（名前は任意。権限の種類はなく、読み取りに使うだけ）
3. 表示されたトークンをコピー（**再表示されない。チャットやリポジトリには貼らない**）

## 2. GASプロジェクトを作る

> 開発ツール系は「AI学習用アカウント」で作る方針（ルート`CLAUDE.md`「Googleアカウント方針」）。

1. https://script.google.com → **新しいプロジェクト**（名前: `cpt-tracker-proxy`）
2. 既定の`コード.gs`の中身を全部消し、このリポジトリの`apps/cpt-tracker/gas/Code.gs`を貼り付けて保存
3. 左の歯車（**プロジェクトの設定**）→ **スクリプト プロパティ** → **スクリプト プロパティを追加**
   - `STARTGG_TOKEN` = 手順1のトークン
   - `EVENT_ID` = `1602225`（EVO France 2026 SF6。他イベントに切り替える時はここだけ変える）

## 3. 動作確認（エディタ）

1. エディタ上部の関数選択を `debugRun` にして **実行**（初回は権限承認: 外部サービスへの接続・キャッシュ）
2. **実行ログ**に `{"ok":true,"fetchedAt":...,"eventState":"ACTIVE",...,"aliveCount":...}` が出ればOK
   - `ok:false` + `Invalid authentication token` → トークンの貼り間違い
   - `start.gg: ...GraphQLエラー` → エラー文をそのままClaudeに共有

## 4. ウェブアプリとしてデプロイ

1. 右上 **デプロイ** → **新しいデプロイ** → 種類: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
2. **デプロイ** → 表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピー
3. ブラウザでそのURLを直接開き、JSONが表示されることを確認（**URLに `/macros/u/数字/s/` が混ざっていたら `/u/数字` の部分を消す**。複数アカウントでログインしているとブラウザが付け足すもので、このままだと「現在、ファイルを開くことができません」になる。正しい形は `https://script.google.com/macros/s/…/exec`）

## 5. アプリに設定

`apps/cpt-tracker/data/config.json` の `"apiUrl": ""` にウェブアプリのURLを入れてコミット（またはClaudeにURLを伝える）。トークンはURLに含まれないので公開リポジトリに書いて問題ない。

## 運用メモ

- 応答は60秒キャッシュ。キャッシュ切れの瞬間も、更新できるのは1人だけで、他の人は待たずに**前回の応答**（`stale:true`）を即座に受け取る。start.ggが一時的に落ちていても、前回の応答があればそれを返す（画面に「データが古い可能性」と出る）。同時に大勢が開いても詰まりにくい。クライアントは約60秒間隔（±10秒のばらつき）で取得するので、start.ggのレート制限（80回/分）には当たらない
- 応答には、直近に終了した試合（`recentSets`、最大8件）も含む。画面の「直近の出来事」はこれを使う。**GASを更新していない間は、画面は「この画面で見た変化」だけの速報にフォールバックする**。このクエリが失敗しても順位・生存者の応答は壊れない（`recentSets`が無くなるだけ）
- GASのコードを変更した場合は **デプロイを管理 → 鉛筆アイコン → バージョン: 新バージョン → デプロイ**。「新しいデプロイ」にするとURLが変わる
- アクセスできるユーザーを「全員」にしているが、返すのは公開されている大会の順位だけ。トークンはレスポンスに含まれない
- トークンを漏らした疑いがある場合は、start.ggのDeveloper Settingsで再発行し、スクリプトプロパティを更新する
- クライアントの`EVENT_ID`を変える以外の入力は受け付けない（任意のイベントをトークンで引かれないようにするため）
